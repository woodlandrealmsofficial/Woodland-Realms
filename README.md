# Woodland Realms Website

GitHub Pages-ready standalone Woodland Realms Minecraft RPG server website.

## Original 15-section structure
1. Realm Gate
2. About the Realm
3. World Map
4. Lore Library
5. Gameplay
6. Quests
7. Bestiary
8. Items & Recipes
9. Character Builder
10. Server Guide
11. Community
12. Development Map
13. Realm Chronicle
14. Vote / Support
15. Staff Hall

The existing fantasy loader, wooden-door page transitions, custom cursor, ambient effects, interactive atlas, and responsive foundation are preserved.

Official GitHub organization: https://github.com/woodlandrealmsofficial
