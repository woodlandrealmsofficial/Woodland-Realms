# Woodland Realms Website

GitHub Pages-ready standalone Woodland Realms Minecraft RPG server website.

## Original 15-section structure
1. Realm Gate
2. About the Realm
3. World Map
4. Lore Library
5. Gameplay
6. Quests
7. Bestiary
8. Items & Recipes
9. Character Builder
10. Server Guide
11. Community
12. Development Map
13. Realm Chronicle
14. Vote / Support
15. Staff Hall

The existing fantasy loader, wooden-door page transitions, custom cursor, ambient effects, interactive atlas, and responsive foundation are preserved.

Official GitHub organization: https://github.com/woodlandrealmsofficial


### v1.5 presentation notes
The first visit now uses the full loader followed by the wooden doors opening into the page. Internal page navigation closes the doors before moving to the next page, and subsequent pages use a shorter door-opening entrance. The 15-section navigation is preserved but switches to the mobile menu earlier to avoid desktop-width crowding.


## v1.5 visual restoration
Restores the original portfolio-aligned loader track positioning, BRASHEXODUS wooden-door travel plaque, opening/closing transition sequence, hand-drawn falling leaves, large ivy cursor, and functional fantasy scrollbar. The original 15-section Woodland Realms site plan remains unchanged.
