The existing project history includes an enormous quest ambition. The new site gives those quests a clean original framework where they can eventually be loaded from Supabase and filtered by region, level, chain, profession and status.

Quest scale

A library built for more than 1,400 adventures.

The project's established quest vision includes NPC stories, puzzles, treasure hunts, profession tasks, exploration trails, secrets, and large story arcs. The website intentionally previews the system without publishing every answer or spoiler.

Story
